# Portfolio

My personal portfolio, built with React, TypeScript and Vite. Each project card shows a live, scaled-down preview of the deployed site.

## Projects

- [CampusKit](https://campuskit-one.vercel.app/): equipment checkout tracker
- [Car Auction](https://carauction-ten.vercel.app/): car auction marketplace
- [Cat Facts](https://catfacts-gamma.vercel.app/): random cat facts

## Run locally

```bash
npm install
npm run dev
```

Project content lives in `src/data/projects.ts`.
